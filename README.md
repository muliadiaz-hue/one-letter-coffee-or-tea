A one-letter answer to the coffee-or-tea question: this program writes
`A` (coffee) to `entry.txt`. The survey behind it found coffee the more
vivid and funnier choice — sharp aroma, dark roast, the caffeine jolt,
and a coffee culture full of memes — and the judge picks the letter that
feels more vivid, funnier or truer.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
